# Marker Creator V3

Flutter Android app for garment marker planning.

V3 includes:
- Fabric width, marker length and fabric price.
- Draw irregular polygon pieces by tapping points.
- Piece quantity.
- Select and drag pieces.
- Two-finger rotation for selected piece.
- Piece area and estimated fabric cost based on its share of marker area.
- Marker efficiency and waste.
- Local save/load of project.
- GitHub Actions Android APK build.

Note: V3 uses the marker canvas dimensions as the calibration space. The next iteration can add point-to-point calibration and richer nesting/placement controls.
