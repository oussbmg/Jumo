# Marker Creator - Prototype

Flutter prototype for creating a fabric marker and calculating basic marker efficiency.

## Run
flutter pub get
flutter run

This first version supports:
- fabric width / marker length / fabric price
- adding rectangular pieces
- moving pieces inside the marker
- double-tap to edit a piece
- importing a marker image filename
- marker area, pieces area, efficiency, waste and marker fabric cost

Next version should add polygon/freehand piece outlines, real image calibration, rotation handles,
piece quantities, saving markers, automatic nesting, and full product costing.
